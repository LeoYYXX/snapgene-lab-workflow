`primers.csv` is a fictional primer table for the Example plant project.

- `PID-000001` … are internal ids (stable, never reused).
- Unsynthesized rows use functional names (`UTR-EXA1-F`, `IF-EVFLAG-EXA1-R-TAA`).
- `PID-000007` / `000008` already have vendor serials `Pr0001` / `Pr0002`, as if that order had been sent — this is only to show the naming rule.
