# Example sequencing-run folder (no traces)

This folder shows the layout only. It does **not** contain real `.ab1` files or invented base calls.

Suggested contents of a real run (do not fabricate them):

- the unzipped `.ab1` traces
- a `manifest.txt` listing sample names vs construct file
- `report.md` with alignment summaries written after the traces are actually aligned to the in-silico construct
- a copy or pointer to the zip that arrived in `seq/inbox/`

Write confirmed results back into the construct `.dna` with sgffp only, after a backup.
